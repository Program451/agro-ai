ESP32 И OBS — ПОДКЛЮЧЕНИЕ К AGROAI

OBS
1. Запустите OBS на ноутбуке. Добавьте нужный источник в сцену:
   веб-камеру, экран, медиафайл, видеоустройство или сетевой источник.
   Телефон и дрон сначала должны передавать видео в OBS способом,
   который поддерживает конкретное устройство.
2. В OBS нажмите «Запустить виртуальную камеру» (Start Virtual Camera).
3. Откройте AgroAI в браузере на том же ноутбуке.
4. Выберите «Камера / OBS» и нажмите «Подключить OBS» в области просмотра.
   Если браузер запросит доступ к камере, разрешите его.
   При первом подключении камера по умолчанию может кратко открыться для
   получения названий устройств; затем сайт выберет именно OBS.
5. Для ручного выбора доступны «Найти камеры», список источников и
   «Запустить камеру». Кнопка поиска сама по себе не запускает видео.
6. Дальше переключайте сцены и источники прямо в OBS.
   AgroAI получает итоговый выход виртуальной камеры; менять сайт не нужно.

Если OBS отсутствует в списке, проверьте, что виртуальная камера запущена,
обновите список или перезапустите браузер. Сайт на хостинге должен иметь HTTPS.
Если появилась ошибка «Permission denied by system», доступ к камере
запрещён браузером или Windows. При работе внутри ChatGPT скопируйте адрес
сайта в отдельный Chrome, Edge или Яндекс Браузер на этом ноутбуке.
Разрешите камеру для сайта. Если запрет остаётся, проверьте в параметрах
Windows раздел «Конфиденциальность и безопасность → Камера», включая
разрешение для классических приложений. Затем обновите сайт.
Сам сайт не может отменить запрет Windows или браузера.
Поиск устройств не открывает камеру по умолчанию, если названия камер
уже доступны. Иначе временное разрешение требуется для получения названий.
На другом устройстве браузер не видит виртуальную камеру ноутбука.
Телефон и дрон выбираются как источники в OBS, отдельной вкладки на сайте нет.
Если в кадре большие чёрные поля, выберите источник камеры в OBS и нажмите
«Преобразовать → Подогнать по размеру экрана» (Ctrl+F). Текущий источник
камеры ноутбука уже подогнан под всю сцену. На сайте просмотр имеет пропорции
16:9 и ширину не более 640 пикселей, уменьшаясь на узком экране.

Официальная инструкция OBS: https://obsproject.com/kb/virtual-camera-guide

ESP32
Панель принимает пять показаний:
- temperature_c: температура в градусах Цельсия;
- humidity_pct: влажность воздуха в процентах;
- pressure_hpa: давление в гПа (если библиотека возвращает Па, разделите на 100);
- altitude_m: высота в метрах;
- rain_raw: целое сырое значение датчика дождя;
Датчик почвы не установлен; soil_raw из старых пакетов игнорируется.

Rain не переводится в проценты: для этого нужны модель датчика,
схема подключения и калибровка сухого/влажного состояния.
Нулевое значение действительно отображается как 0, а не как «Нет данных».

На ноутбуке выполните python setup.py. В .env появится AGRO_SENSOR_TOKEN.
Это отдельный ключ: он разрешает ESP32 только запись показаний.
Ключ AGRO_API_TOKEN на ESP32 копировать не нужно.

ESP32 отправляет POST /api/sensors прямо на Python, не через frontend/api.php.
Заголовки: Content-Type: application/json и X-Sensor-Token: ваш ключ.
Тело запроса содержит device_id и указанные выше поля. Можно отправлять
часть полей; отсутствующие значения будут показаны прочерком.

Вариант A — одна доверенная Wi-Fi сеть
1. В .env на ноутбуке задайте AGRO_HOST=0.0.0.0 и перезапустите Python.
2. Разрешите входящий TCP 8000 только в своей частной сети в брандмауэре.
3. Узнайте локальный IP ноутбука (например, 192.168.1.100).
4. В скетче укажите http://IP-НОУТБУКА:8000/api/sensors.
HTTP передаёт ключ без шифрования, поэтому этот вариант только для
доверенной локальной сети. На роутере открывать порт в Интернет не нужно.
Изменения брандмауэра и привязки адреса автоматически не выполнялись.

Вариант B — HTTPS-туннель
Укажите https://АДРЕС-ТУННЕЛЯ/api/sensors и доверенный корневой сертификат
в ROOT_CA. На ESP32 должно быть правильное время. Проверку TLS не отключайте.
Для этого варианта Python может оставаться на 127.0.0.1.

Код интеграции: esp32/agroai_sender.h.
Пример скетча: esp32/agroai_example/agroai_example.ino.
Скопируйте agroai_sender.h рядом с .ino, заполните Wi-Fi и ключ, затем
подключите свои реальные переменные в readYourSensors(). Модели датчиков
и пины пока неизвестны, поэтому пример не выбирает библиотеки и не
генерирует выдуманные показания. Передача выполняется каждые 5 секунд.

Панель обновляется каждые 5 секунд. Через 120 секунд без показаний
появляется отметка «Данные устарели», время последнего получения остаётся.
Показания сохраняются в data/sensors.sqlite3 на ноутбуке; сохраняются
последние 10 000 записей. До первого реального пакета отображаются прочерки.

Фото, видео и API проверены программно. Подключение к OBS Virtual Camera
проверено в браузере: сайт показывает реальное изображение сцены с камерой
ноутбука. Если виден логотип с перечёркнутой камерой, запустите виртуальную
камеру в OBS. «Начать запись» — другая функция, она не включает видеовыход.
Подключение телефона, дрона, физической ESP32 и датчиков ещё требует проверки.
