EginQanat AI: САЙТ НА ХОСТИНГЕ, ИИ НА НОУТБУКЕ

Сайт: https://dron.itudron.ru/agro-ai/frontend/

Перед первым запуском из GitHub установите зависимости из requirements.txt
и выполните setup.py (команды в README.md). Добавьте свой GEMINI_API_KEY в .env.
Скачайте Windows-версию cloudflared с официального сайта Cloudflare,
создайте папку tools и сохраните программу как tools/cloudflared.exe.
Исполняемый файл cloudflared и секреты в репозиторий не включены.

1. На ноутбуке откройте start-hosting.bat в папке проекта.
   Программа запускает Python при необходимости и временный HTTPS-туннель.
   Дополнительные Python-библиотеки не требуются.

2. Дождитесь надписи «Подключение ноутбука готово».
   Откроется папка run/hosting с файлом config.local.php.

3. Через файловый менеджер вашего хостинга загрузите config.local.php
   в папку agro-ai/frontend/ рядом с index.php, api.php и config.php.
   Если такой файл уже есть, замените его. Содержимое файла менять не нужно.
   Файл содержит служебный ключ связи. Не публикуйте его в GitHub.
   Файл .env и ключ Gemini на хостинг загружать не нужно.

4. Обновите сайт. Индикатор должен показать, что модель подключена.
   Для камеры выберите OBS Virtual Camera и включите её в OBS Studio.
   Gemini запускается кнопкой «Начать общий анализ» на сайте.

Пока нужен анализ, оставляйте ноутбук включённым, подключённым к Интернету,
и не закрывайте окно запуска. Ctrl+C останавливает туннель и запущенный
этой программой Python. Если Python работал раньше, он продолжит работать.

После каждого нового запуска туннеля адрес меняется: повторите шаг 3
с обновлённым config.local.php. Это временное подключение для первого
запуска и проверки. Для постоянного адреса нужен настроенный постоянный
туннель Cloudflare с доменом.

Если запуск не удался, журналы находятся в run/hosting/.
Скрипт не изменяет frontend/config.local.php на ноутбуке: локальный запуск
через start-local.bat сохраняет свои настройки.

Локальная модель YOLO работает на ноутбуке. Gemini обрабатывает запросы
через API Google и требует Интернета.

Cloudflare: https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/
