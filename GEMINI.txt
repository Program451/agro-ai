EginQanat AI — Gemini, OBS и ESP32

Запуск
1. Запустите start-local.bat для локального сайта. Если сайт уже на хостинге,
   включите start-hosting.bat на ноутбуке (подготовка в HOSTING-CONNECTION.txt).
2. В OBS выберите сцену телефона, дрона или камеры и включите виртуальную камеру.
3. На сайте выберите «Камера / OBS», затем «Подключить OBS».
4. Датчик выбирается автоматически: последнее устройство, приславшее данные.
5. Нажмите «Gemini + датчики». Для камеры запускается AI-наблюдение,
   для фото/файла — один запрос. Gemini получает кадр и данные датчиков.
   Локальная разметка моделью YOLO включается кнопкой «Начать анализ».

Что отправляется
- Один JPEG-кадр без разметки, уменьшенный до 1280 пикселей по длинной стороне.
- Последние доступные показания выбранного ESP32, их возраст и история за
  последние 30 минут: до 360 пакетов для расчёта изменений, до 12 выборочных
  пакетов передаются модели. Показания разных устройств не смешиваются.
- Предположения локальной модели и сводки последних трёх
  отчётов того же сеанса. Старые изображения в очередной запрос не отправляются.
- Микрофон не используется, непрерывное видео в Gemini не передаётся.

Частота и остановка
Первый запрос отправляется сразу после запуска. Следующий — через 30 секунд
после ответа (технический запас 1 секунда). Одновременно выполняется один
AI-запрос. Сеанс ограничен 30 минутами. Нажатие «Остановить AI», остановка
камеры, смена файла/раздела, скрытие или закрытие вкладки останавливают режим.
Вновь запускайте его кнопкой. Запрос, который уже дошёл до Gemini, отменить
гарантированно нельзя: его отчёт может сохраниться в журнале.
Ошибки доступа/квоты останавливают наблюдение; после трёх прочих ошибок оно
также останавливается. Каждый запрос расходует квоту вашего проекта Google.
Ключ в настройке сам по себе не подтверждает наличие квоты.

Результаты
Отчёт содержит наблюдения, условные риски на 24–48 часов, действия для проверки
и ограничения. В журнале на ноутбуке хранятся последние 500 кадров с отчётами
и использованными показаниями; сайт показывает последние 50. Можно открыть
кадр и скачать выбранный отчёт в JSON.
Это запись отдельных наблюдений. Полную видеозапись включайте отдельно в OBS.
Для фото и загруженной видеозаписи кнопка «Gemini + датчики» анализирует
фото или кадр на текущей позиции проигрывателя исходного файла. Текущая
телеметрия не выдаётся за показания на момент съёмки старой записи.

Точность времени и датчиков
К живому кадру выбираются только пакеты, полученные сервером до времени кадра.
Часы браузера и ноутбука должны быть настроены правильно. Пакет старше 120 секунд
отмечается устаревшим. Для прямого приёма это время на ноутбуке; для данных
с хостинга — исходное время записи CSV, а не момент его загрузки в Python.
Задержка передачи ESP32 не измеряется. Датчик должен находиться
на том же участке, который показан камерой.
Для тренда требуется не менее двух замеров с интервалом хотя бы в минуту.
Rain и Soil остаются сырыми ADC: без калибровки они не являются процентом
влажности почвы или количеством осадков. Нет датчиков — отчёт явно это отмечает.
Прогноз условный: что возможно, если условия сохранятся. Погода, урожайность,
точный диагноз и гарантированный результат не вычисляются. Комната, человек
или заставка OBS не должны интерпретироваться как поле.

Ключ и перенос на другой компьютер
Ключ хранится только в .env рядом с server.py:
GEMINI_API_KEY=ВАШ_КЛЮЧ
GEMINI_MODEL=gemini-3.5-flash-lite

После изменения .env перезапустите бэкенд. .env исключён из Git,
как и базы данных, журналы и frontend/config.local.php. В репозитории есть
.env.example с пустым местом для ключа. На другой компьютер ключ нужно
перенести отдельно; на PHP-хостинг GEMINI_API_KEY не загружайте.
Сам .env — обычный локальный файл, а не шифрованное хранилище.
Запрос к Google выполняется только Python-сервером по HTTPS. Ключ не включается
в URL, браузерный JavaScript, HTML или API-ответы. Сырые ошибки провайдера
пользователю не возвращаются.
Если сайт доступен другим людям, они тоже могут пользоваться AI-кнопками:
ограничьте доступ к своему сайту средствами хостинга, если он предназначен
только для вас. Секрет в .env не является входом для посетителей сайта.

Библиотеки
Дополнительный SDK Gemini устанавливать не нужно. Используется requests,
который уже находится в requirements.txt:
python -m pip install -r requirements.txt

Основные библиотеки: FastAPI, Uvicorn, Pydantic, python-multipart, OpenCV,
NumPy, ONNX Runtime, requests, python-dotenv. SQLite входит в Python.
PHP 8.1+ с cURL нужен для фронтенда. FFmpeg нужен для браузерного MP4.
OBS Studio нужен для выбора камеры/дрона/телефона.

Официальная документация:
https://ai.google.dev/gemini-api/docs/image-understanding
https://ai.google.dev/gemini-api/docs/generate-content/structured-output
