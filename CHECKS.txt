EginQanat AI — история проверок

Упрощение интерфейса 22.10.2026:
- Убраны карточка почвы, ползунок порога, нижние счётчики и подсказки,
  раздел «Как это работает» и его кнопка навигации.
- Порог 35% фиксирует PHP-шлюз, включая кадры камеры; остальные данные
  запроса сохраняются. Семь проверок с локальным тестовым бэкендом прошли.
- 13 существующих проверок JavaScript и синтаксические проверки PHP прошли.

Проверено перед публикацией в GitHub 22.10.2026:
- 25 тестов Python прошли, включая исходную модель ONNX и импорт CSV с хостинга.
- 13 тестов JavaScript прошли: камеры, единая кнопка Gemini и остановка наблюдения.
- PHP-тест чтения CSV и синтаксическая проверка всех PHP-файлов прошли.
- В автоматических тестах Gemini подменяется; реальные запросы не отправляются.
- В текущем интерфейсе одна кнопка «Начать общий анализ»; поля культуры, участка
  и ID убраны. Датчик выбирается автоматически — последнее устройство.
- Добавлены исходники существующего приёмника и страницы метеостанции.

Ранее проверено локально (20.10.2026):
- Python API загружает исходный best.onnx.
- PHP-интерфейс открывается на http://127.0.0.1:8080/.
- Снимок из исходного проекта проходит через PHP в Python и возвращается с разметкой.
- Видео принимается в очередь, обрабатывается и скачивается в H.264 через PHP.
- Частичное скачивание видео возвращает HTTP 206.
- 21 автоматический тест Python прошёл.
- PHP-файлы и JavaScript прошли синтаксическую проверку.
- Панель датчиков отображает «Нет данных» до первого реального пакета.
- Показания ESP32 сохраняются в SQLite; отдельный ключ допускает только их отправку.
- Нулевые значения не теряются, просроченные показания отмечаются как устаревшие.
- Выбор OBS Virtual Camera и обычной камеры доступен в интерфейсе.
- Пять тестов подключения камеры: системный запрет, отсутствие HTTPS,
  поиск OBS без открытия занятой веб-камеры, получение названий и освобождение
  временного видеопотока при успехе и ошибке.
- При запрете камеры интерфейс показывает инструкцию и адрес для отдельного браузера.
- OBS Virtual Camera найдена в браузере, кадры доходят до модели через PHP.
  В OBS включена виртуальная камера; реальное изображение сцены видно на сайте.
  В области просмотра добавлена кнопка «Подключить OBS» для запуска без прокрутки.
- Убрана вкладка «Дрон», остаются фото, видео и камера / OBS.
- Источник камеры в OBS подогнан под размер сцены; браузер получает 1280×720.
  Просмотр ограничен шириной 640 пикселей и сохраняет пропорции 16:9.
- При проверке ширины 390 и 1440 пикселей горизонтального переполнения страницы нет.

Не проверено без ваших подключений:
- Подключение телефона и дрона к сценам OBS (проверена сцена с камерой ноутбука).
- Прошивка и показания конкретных датчиков ESP32: их модели и пины не заданы.
- Одновременные реальные показания ESP32 и камера поля: физические датчики пока не присылают данные.

- Панель читает сохранённые пакеты ESP32 из data.csv на хостинге.

Gemini — проверено 20.10.2026:
- Ключ в локальном .env; доступ к Gemini и реальная генерация подтверждены.
- Через кнопки PHP-сайта отправлен снимок из исходного проекта. Gemini вернул
  структурированный отчёт примерно за 11 секунд. Отчёт и кадр сохранены в журнале.
- На снимке распознаны постройки/теплицы; прогноз рисков поля не выдуман.
  Отсутствие ESP32 и несовпадение времени файла с текущими показаниями отмечены.
- Запрос выполняется в фоновой очереди Python. PHP возвращает номер задания
  сразу, затем сайт проверяет готовность короткими запросами.
- 13 новых тестов проверяют синхронизацию, историю одного ESP32, нулевые
  показания, идемпотентность, ограничения частоты, структуру ответа и ошибки.
  Ещё один тест проверяет очередь, защищённые журнал и снимки через API.
- Девять тестов JavaScript прошли: пять прежних для камеры и четыре для
  AI-наблюдения — отсутствие параллельных запросов, остановка, смена сеанса,
  остановка при исчерпании квоты.
- Секреты не выводятся в интерфейс, сырые ответы ошибок Google не возвращаются.
- Модель Gemini не является подтверждённой агрономической диагностикой.
  Автоматические тесты не измеряют точность прогнозов на реальном поле.
