# AgroAI Scout

Веб-приложение для анализа поля с помощью вашей модели YOLO11 (`best.onnx`).
Поддерживает 4 режима работы:

- **Фото** — загрузка снимка поля/растения, разметка вредителей и состояния поля.
- **Видео** — загрузка видеозаписи обхода поля, аннотированное видео на выходе + график активности по времени.
- **Камера** — веб-камера ноутбука/ПК, анализ в реальном времени прямо в браузере.
- **Дрон** — подключение к видеопотоку дрона или IP-камеры (RTSP / HTTP MJPEG), аннотирование на сервере в реальном времени.

Модель распознаёт 22 класса: 16 видов вредителей (тля, клопы, долгоносики, проволочники и т.д.)
и 6 состояний поля (здоровое, повреждённое, заросшее, вспаханное, замусоренное).

Инференс идёт через **ONNX Runtime** — torch/ultralytics для запуска не нужны, только `best.onnx`.

## Установка

```bash
cd AgroAI
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```bash
python server.py
```

Откройте в браузере: **http://127.0.0.1:8000**

## Режим «Дрон»

Приложение подключается к любому потоку, который умеет открыть OpenCV:

- `rtsp://IP:PORT/путь` — если дрон/полётный контроллер отдаёт RTSP-поток;
- `http://IP:PORT/video` — HTTP MJPEG (многие IP-камеры и приложения типа «IP Webcam» на телефоне);
- `0` — камера, физически подключённая к компьютеру, на котором запущен сервер.

Если у дрона нет прямого видеовыхода на компьютер, самый простой вариант для теста —
закрепить телефон с приложением-IP-камерой на дрон/шест и указать его адрес в этом поле.
Сервер сам читает поток, прогоняет каждый кадр через модель и отдаёт в браузер уже
готовое видео с рамками обнаружений.

## Структура проекта

```
AgroAI/
├── server.py       — FastAPI-сервер и все API-эндпоинты
├── engine.py       — обёртка над ONNX Runtime: препроцессинг, NMS, отрисовка рамок
├── best.onnx       — ваша обученная модель YOLO11 (экспортирована из best.pt)
├── requirements.txt
└── static/
    └── index.html  — весь интерфейс (HTML/CSS/JS в одном файле)
```

## Настройка порога уверенности

На каждой вкладке есть слайдер «Порог уверенности» (0.1–0.9) — чем выше значение,
тем меньше ложных срабатываний, но модель может пропустить слабо выраженные объекты.
По умолчанию 0.35 — хороший баланс для полевых снимков.

## Если нужно расширить

- **Список классов и цвета** — правятся в `engine.py` (`CLASS_NAMES`, `CLASS_COLORS`).
- **Скорость обработки видео** — параметр `max_seconds` в запросе `/api/detect/video`
  (по умолчанию обрабатывается до 60 секунд ролика, кадры уменьшаются до 960 px по большей стороне).
- **Частота анализа кадров камеры/дрона** — `detect_every` в `server.py` (видео) и
  интервал `500` мс в `static/index.html` (веб-камера).
